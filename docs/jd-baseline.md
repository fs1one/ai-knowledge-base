# JD 对照表 · 基线

> **JD = Job Description，岗位描述。** 就是招聘软件上每个岗位下面那段「岗位职责 / 任职要求」的文字。
> 抓它的目的：把「中厂实习要什么」从猜测变成证据，尤其是**卡不卡大二**这件事，只有真实 JD 能回答。

## 收集规则

- **目标**：10 天内（10/19–10/28）抓满 **20 条**
- **城市**：长沙 / 深圳 / 武汉 / 杭州，各 5 条
- **搜索词**：`Java 后端 实习`、`Java 开发 实习生`、`后端开发 实习`
- **只要**日常实习 / 实习岗，不要校招正式岗（应届）
- **每条只记 5 个字段**，不要整段复制，浪费时间

**字段怎么填**

| 字段 | 填法 | 为什么要记 |
|---|---|---|
| 年级要求 | 照抄原文，如「大三及以上」「不限年级」「2028 届」 | 直接决定你能不能投 |
| 每周到岗 / 时长 | 如「4 天/周，3 个月」 | 你开学后每周只有 3 天，这条会筛掉一半岗位 |
| 技术栈关键词 | 只记名词，如 `SpringBoot` `MySQL` `Redis` `MQ` `Docker` | 后面统计高频词用 |

## 填写示例（照这个粒度写，不要抄内容）

```markdown
| 1 | 某某网络科技 | 长沙 | 本科及以上，大三/大四优先 | 4 天/周，3 个月起 | SpringBoot、MySQL、Redis、Git |
| 2 | 某某信息技术 | 长沙 | 不限年级，能实习 3 个月以上 | 5 天/周，6 个月 | Java 基础、SpringBoot、MyBatis、Linux |
```

**注意三点**：
1. 「年级要求」**照抄原文**，别自己概括。看到「大三及以上」就写「大三及以上」——这条往往就是筛掉你的那条。
2. 「每周到岗」把天数和月数都记上，缺一个都没法判断。
3. 「技术栈」只记名词，不记句子。出现 `熟悉 SpringBoot` 就写 `SpringBoot`。
